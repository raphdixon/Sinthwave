ARTURIA V COLLECTION 11 // ZERO-CLICK AUTO-ROUTING

Sinthwave automatically pre-writes each Arturia synth's standalone.pref configuration file before launching it so each window opens isolated to its own sequencer track with zero channel bleed:

AUTO-BOUND PORTS

1 Synth = 1 Dedicated Virtual Port

  • Unit 1 (Drums): Built-In 48kHz 808/909 + Emulator II V / CMI V
  • Unit 2 (Moog Bass): Mini V4 / Acid V → Unit 2 Ch2-3 Moog Sub 37 Bass
  • Unit 3 (Prophet/FM Lead): DX7 V / MS-20 V / Prophet-5 V → Unit 3 Ch4 Lead
  • Unit 4 (Minilogue/Kronos): Jun-6 V / CS-80 V4 / Jup-8 V4 → Unit 4 Ch5 Pads
IMPORTANT NOTE

Do NOT Tick "Master Bus (All Ch)"

Arturia standalone apps listen in Omni mode (All Channels) by default. Because Sinthwave pre-selects each unit's dedicated port in standalone.pref, each synth plays only its own part automatically! (If you ever switch audio interfaces while an app is already open, just check ☰ → Audio MIDI Settings).
